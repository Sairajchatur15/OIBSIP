# Task 4: Online Examination System

## Objective

Build a desktop-based online examination application with authentication, a student profile, timed multiple-choice questions, and result reporting.

## Steps Performed

1. Built the user interface using Java Swing and `CardLayout`.
2. Added a login screen and editable student-profile screen.
3. Created a five-question multiple-choice examination with Previous, Next, and Submit controls.
4. Added a 30-minute countdown timer with automatic submission.
5. Calculated the final score and displayed a result screen with logout support.

## Tools Used

- Java
- Java Swing
- `CardLayout`
- Swing `Timer`

## Outcome

The application delivers a complete timed quiz flow from login through score display. The configured password is `admin123`.

## Run

From the `Task4` folder:

```bash
javac OnlineExam\\ExamSystem.java
java OnlineExam.ExamSystem
```
