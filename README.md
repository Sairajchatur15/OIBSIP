# OIBSIP — Java Development Tasks

This repository contains four completed Java Development tasks submitted for the Oasis Infobyte internship. Task 5 is not included.

## Folder Structure

- `JavaDevelopment-Task1-OnlineReservationSystem/`
- `JavaDevelopment-Task2-NumberGuessingGame/`
- `JavaDevelopment-Task3-ATMInterface/`
- `JavaDevelopment-Task4-OnlineExaminationSystem/`

## Task 1: Online Reservation System (Desktop)

- Java Swing interface for login, booking, and cancellation
- SQLite-backed users, trains, and reservations
- PNR creation, booking lookup, validation, and cancellation confirmation

## Task 2: Number Guessing Game (Console)
- Main.java + NumberGuessingGame.java
- Random number 1-100, 7 attempts max
- Too High / Too Low / Correct feedback
- Attempt counter visible
- Play Again loop with round summary ("Round X — guessed in Y attempts")

## Task 3: ATM Interface (OOP, Console)
- Main.java, ATM.java, Account.java, Transaction.java, Bank.java (5 classes)
- Login with User ID + PIN (3 attempts max)
- Menu: Transaction History, Withdraw, Deposit, Transfer, Quit
- Balance validation with "Insufficient Funds" message
- All transactions stored in ArrayList and displayed clearly
- Goodbye message on quit

## Task 4: Online Examination System (Desktop)

- Login and student-profile screens
- Timed multiple-choice examination with question navigation
- Automatic/manual submission, score display, and logout
