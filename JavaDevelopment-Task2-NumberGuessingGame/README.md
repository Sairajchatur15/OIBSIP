# Task 2: Number Guessing Game

## Objective

Create a console game in which the player guesses a randomly generated number.

## Steps Performed

1. Generated a random number from 1 to 100 for each round.
2. Limited each round to seven valid guesses.
3. Added input validation and high/low/correct feedback.
4. Displayed attempt counts, a round summary, and a play-again option.

## Tools Used

- Java
- `Scanner` for console input
- `Random` for number generation

## Outcome

The game runs repeatedly until the player chooses to stop and reports the number of rounds played.

## Run

```bash
javac Main.java NumberGuessingGame.java
java Main
```
